# Word CoUnter v1.2

Счётчик слов для English writing с живой проверкой лимита и панелью статистики текста.

## Скачать

Готовый `.exe` лежит в разделе **Releases** справа на странице репозитория. Python не нужен: скачай и запусти.

> Windows может показать окно SmartScreen, потому что программа не подписана.
> Нажми **Подробнее → Выполнить в любом случае**.

## Запуск из кода

Нужен Python 3.8+ (tkinter идёт в комплекте):

    python main.py

## Возможности

- **Режимы:** Essay (191-259 слов), Email (91-153 слова) и Custom со своими лимитами
- **Живой вердикт:** PASS / TOO SHORT / TOO LONG прямо при печати, с подсказкой, сколько слов добавить или убрать
- **Честный подсчёт слов:** `well-known` и `don't` считаются одним словом, одинокие тире не считаются
- **Панель Stats:** предложения (количество, средняя длина, самое длинное), читаемость по Флешу, уровень и Grade, уникальные слова, средняя длина слова, время чтения и речи, топ повторов
- **Файлы:** Open / Save / Save As для `.txt` (UTF-8 и cp1251)
- **Защита текста:** звёздочка в заголовке и вопрос перед закрытием, Open или Clear, если есть несохранённые изменения
- **Горячие клавиши на любой раскладке (Windows):** Ctrl+C / V / X / A / Z / Y / O / S

## Заметки

- Читаемость и Grade рассчитаны на английский, слоги считаются приблизительно
- Время чтения считается по ~200 слов в минуту, речи по ~130
