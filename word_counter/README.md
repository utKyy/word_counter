# Word CoUnter v1.0

Простой счётчик слов для English writing. Режимы: Essay (191-259), Email (91-153) и Custom.

## Запуск

Нужен Python 3.8+ (tkinter идёт в комплекте).

    python main.py

## Возможности
- Живой счётчик слов, символов и абзацев
- Проверка лимита одной кнопкой
- Ctrl+C / V / X / A работают на любой раскладке (Windows)
